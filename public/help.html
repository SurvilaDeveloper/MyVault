Documentación de MyVault

Guía rápida para usar la aplicación de forma segura y ordenada.

1. Crear una cuenta

  1. Ingresá un nombre de usuario.
  2. Definí tu contraseña de acceso.
  3. Definí una contraseña para el vault.

La contraseña del vault protege el contenido cifrado que guardás dentro.

2. Iniciar sesión

  1. Entrá con tu usuario y contraseña.
  2. Luego desbloqueá el vault con su contraseña específica.

3. Guardar contraseñas

  • Agregá registros con cuenta, usuario y contraseña.
  • Podés mostrar una contraseña puntual cuando lo necesites.
  • También podés usar la vista general para mostrar todas.

4. Usar anotaciones

  • Creá notas privadas dentro del vault.
  • Los cambios deben guardarse antes de cerrar la app.
  • Si hay cambios sin guardar, MyVault te va a avisar.

5. Recomendaciones de seguridad

  • No compartas la contraseña del vault.
  • Usá una contraseña fuerte y única.
  • Recordá cerrar sesión cuando termines.
